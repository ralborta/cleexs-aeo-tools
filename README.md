# Cleexs AEO Toolkit

10 herramientas de análisis AEO en uno: frontend Next.js + backend FastAPI (con integración a OpenAI, Gemini, Perplexity y SerpAPI).

## Deploy

- **Frontend:** Vercel → conectar este repo, **Root Directory** = `frontend`
- **Backend:** Railway → conectar este repo, **Root Directory** = `backend`

Ver [DEPLOY.md](DEPLOY.md) para pasos detallados y variables de entorno.
